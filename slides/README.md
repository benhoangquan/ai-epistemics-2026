# Slides

Source files of the two decks (16:9, one HTML file per slide plus a shared `deck.css` and `deck.json`).
They are published as private claude.ai artifacts of type Slides; the copies here are a backup.

- `A_reliability_scores/`: Which Reliability Score Survives a Learning Cheater? (11 slides)
- `B_ghostwriting_gap/`: Verdict Tests Miss It: LLM Ghostwriting Takes the Narrator's Side (10 slides)

Every number on a slide appears in the matching paper under `papers/`. Speaker notes are in each slide's `<aside>`.

## Videos
`video/` holds one silent-narration video per deck (about 100 s and 89 s, 1920x1080, H.264 with AAC audio).
Each slide is shown for 6 to 11 seconds with a short crossfade. The background music is an original ambient
loop synthesized from sine waves (Am, F, C, G pad with soft plucks), so there is no licensing issue.
They were rendered from the slide sources in this folder.
