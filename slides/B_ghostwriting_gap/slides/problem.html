The problem

People already ask chatbots to write the message they send in a dispute.

TEST WE KNOW

Ask for a verdict

“Who is right?” Existing work reports verdict-level affirmation.

WHAT PEOPLE DO

Ask for a draft

“Write the message for me.” The message gets sent.

Does the draft take the sender’s side, and does a verdict test see it?

The sprint track asks whether chatbots escalate or calm disputes. We start with the narrow question: whose side does the drafted message take? Verdict-level both-sides affirmation is already reported by ELEPHANT and follow-ups, and our verdict replication found no narrator-siding, so we do not claim to overturn it.
